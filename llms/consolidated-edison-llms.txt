# Consolidated Edison (Con Edison)

> Con Edison is a Fortune 500 investor-owned utility delivering electric, natural gas and steam service to New York City and Westchester County. It runs no general-purpose developer portal. Its one programmatic surface is Green Button Connect My Data ("Share My Data") — a NAESB ESPI REQ.21 / Green Button V3.3 API that lets a registered third party retrieve a customer's interval energy usage, billing and account data after that customer grants consent. Access requires signing a Data Security Agreement and completing a 30-60 day technical onboarding with Con Edison; there is no self-service signup and no public sandbox.

This file was generated by API Evangelist from Con Edison's own published documents. Con Edison does not publish an llms.txt.

## APIs

- [Green Button Connect My Data](https://www.coned.com/en/accounts-billing/share-energy-usage-data/become-a-third-party): OAuth 2.0 + ESPI Atom/XML API. Production base https://api.coned.com/gbc/espi/1_1, test base https://apit.coned.com/gbc/espi/1_1. 37 operations across UsagePoint, MeterReading, IntervalBlock, ReadingType, UsageSummary, RetailCustomer, Batch, RealTime and Authorization.
- [Green Button Download My Data](https://www.coned.com/en/save-money/make-better-energychoices-with-green-button): customer-initiated CSV / ESPI XML export of up to a year of smart-meter interval data from My Account. No API integration required.

## Getting access

1. Register your company on the [Third-Party Company Registration Form](https://www.coned.com/en/accounts-billing/share-energy-usage-data/become-a-third-party/registration-form).
2. Complete and sign the Data Security Agreement. No response within 90 days withdraws the submission.
3. Submit the technical onboarding registration form; Con Edison emails back client_id, client_secret and a Registration Access Token.
4. Build the customer authorization workflow and pass API testing in the test environment with Con Edison's team. Testing must complete within 90 days of acceptance.
5. Re-register with production details. Expect 30 to 60 days end to end. Contact: dlsharemydatatech@coned.com

## Limits worth knowing before you build

- Two years of historical usage and billing data; real-time data is electricity only, last 24 hours, with 45 minutes of latency and is explicitly not billing quality.
- All query timestamps must be UTC, computed with the correct EST/EDT offset. Interval counts per day change across DST boundaries (288 normal, 276 spring forward, 300 fall back).
- Every reading value must be scaled by its ReadingType powerOfTenMultiplier; Con Edison currently uses 3 for electric and 0 for gas.
- An authorization is revoked automatically if unused for 365 days.
- Batch responses must be collected within 2 days of notification.
